H5 Validator

H5 Validator checks selected HTML5 creative packages and reports common QA issues such as ZIP structure, HTML/CSS/JavaScript concerns, dimensions, file size, clickTag or exit-link implementation, missing assets, and platform-related requirements.

The ZIP will not open.

Confirm that the file is a valid ZIP archive and that the creative files are not corrupted. Re-export the creative package and try again.

A warning does not mean the ad is definitely invalid.

Some checks are best-practice or platform-specific warnings. Review the finding against the trafficking platform and campaign requirements before making changes.

Pixel Comparer

Pixel Comparer is intended for visual QA between user-selected images. For best results, compare images with matching dimensions and use the slider, fade, flicker, or overlay controls to isolate differences.

The comparison looks misaligned.

Verify that both source images use the same dimensions and crop. Differences in canvas size or exported padding can make otherwise matching elements appear offset.

Ad Comparer

Ad Comparer provides a side-panel workspace for loading reference and local ad content, adjusting dimensions and positions, and reviewing creatives next to each other.

A URL or local file does not load.

The destination may block framing, local-file access may be disabled in Chrome, or the page may require authentication. For local files, review the extension’s “Allow access to file URLs” setting where applicable.

Side Comparer

Side Comparer provides a focused Chrome side panel for quick text and image comparison.

The side panel does not open.

Open chrome://extensions, confirm Side Comparer is enabled, then reload Chrome or the active page and try again.

General FAQ

No. RFE tools are independently developed and are not affiliated with, sponsored by, or endorsed by Google.

How do I report a bug?

Email raniel.escalante@gmail.com with the extension name, version, Chrome version, reproduction steps, and any useful screenshots.

How do I request a feature?

Send a support email with the tool name and a short description of the workflow you want to improve.
