Privacy Policy

How RFE Chrome tools handle files, browser content, settings, and support communications.

ScopeData HandlingBy ToolSharingRetentionSecurityLimited UseContact
Effective date: September 9, 2026. This policy applies to RFE’s H5 Validator, Pixel Comparer, Ad Comparer, Side Comparer, and this website.

1. Scope

RFE develops browser-based utilities for creative QA and comparison. This policy explains the categories of information the tools may access to provide their user-facing features and how that information is handled.

2. General Data Handling

RFE tools are designed around local browser workflows. Files or images you deliberately select for validation or comparison are processed in the browser for the requested task. RFE does not operate an account system, advertising network, analytics profile, or central upload service for these tools.

Some tools may store user preferences or comparison state using Chrome’s local extension storage so settings can persist between sessions. Local extension storage remains on the user’s browser profile unless removed by the user, Chrome, or the extension.

3. Tool-Specific Practices

H5 Validator

When you select an HTML5 ZIP package, H5 Validator reads the package contents in the browser to perform validation checks. The selected creative files are not intentionally transmitted to an RFE server as part of the validation workflow.

Pixel Comparer

User-selected comparison images are loaded into the browser for visual comparison. The comparison workflow is designed to use local browser object references rather than upload the selected images to RFE.

Ad Comparer

Ad Comparer may access URLs or local file locations that you provide in order to display and compare ad content. It uses Chrome side-panel functionality and may save comparison settings locally using Chrome storage. Because webpages can contain user or site data, Ad Comparer only uses page access to support comparison functionality initiated by the user.

Side Comparer

Side Comparer provides a Chrome side-panel workspace for user-directed comparison. Content supplied to the comparison interface is used to provide that comparison experience.

4. Sale, Sharing, and Advertising

RFE does not sell extension user data. RFE does not use extension user data for personalized advertising, credit decisions, or data-broker activity. RFE does not transfer extension user data to third parties except when necessary to provide a user-requested feature, comply with law, or protect users and the service.

5. Retention and Deletion

RFE does not maintain a central repository of the creative files selected in the local workflows described above. Locally stored extension settings may remain in Chrome storage until the extension data is cleared or the extension is removed. Support emails are retained only as reasonably necessary to respond to requests, maintain support history, and address abuse or legal obligations.

6. Security

RFE aims to minimize requested permissions and use browser-provided APIs for extension functionality. When external network communication is required by a tool or destination selected by a user, security also depends on the destination website and browser environment.

7. Chrome Web Store Limited Use

RFE’s use of information received from Chrome or Google APIs will adhere to the Chrome Web Store User Data Policy, including its Limited Use requirements. User data is used only as necessary to provide or improve the disclosed user-facing functionality of the relevant extension, subject to applicable law and policy.

8. Changes to This Policy

This policy may be updated when an RFE tool changes its functionality, permissions, or data practices. The effective date at the top of this page will be updated when material changes are published.

9. Contact

For privacy or support questions, contact raniel.escalante@gmail.com.

This privacy policy is intended to accurately describe the current RFE tools based on their implemented functionality. It is not legal advice.
