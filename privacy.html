Privacy Policy

A clear explanation of what RFE Chrome tools access, why they access it, where processing occurs, and when information may be shared.

1. Privacy Summary

RFE develops H5 Validator, Pixel Comparer, Ad Comparer, and Side Comparer for creative-quality-assurance and comparison workflows. The extensions are designed to process user-selected content locally in the browser whenever the feature permits. RFE does not sell extension user data and does not use extension user data for personalized, retargeted, or interest-based advertising.

This policy describes the current intended data practices of the RFE tools. The permissions and Chrome Web Store privacy disclosures for each published extension must remain consistent with its actual behavior and this policy.

2. Scope

This policy applies to the RFE website and the RFE Chrome extensions named above. “User data” in this policy includes information or content a user deliberately supplies to an extension and information an extension accesses through Chrome permissions to perform a disclosed user-facing function.

3. Categories of Data Accessed or Processed

Depending on the extension and feature used, RFE tools may process:

  • User-selected files and images: creative ZIP packages, HTML5 assets, screenshots, reference images, or comparison images deliberately selected by the user.
  • User-provided URLs and displayed web content: where a comparison feature requires loading a URL or displaying content selected by the user.
  • Extension settings and workflow state: preferences, dimensions, positions, or other configuration required to preserve the user’s workspace.
  • Technical support information: information a user voluntarily sends by email, such as extension version, Chrome version, screenshots, reproduction steps, and problem descriptions.

RFE does not intentionally request payment-card information, government identification numbers, passwords, health information, or other sensitive information for these tools. Users should not submit such information through support communications.

4. How Each Tool Uses Data

H5 Validator

When a user selects an HTML5 creative package, H5 Validator reads the selected package and its contained assets to perform the validation requested by the user. The purpose is limited to identifying relevant creative-QA issues. The selected package is intended to be processed locally and is not intentionally uploaded to an RFE server as part of the validation workflow.

Pixel Comparer

Pixel Comparer processes images deliberately selected by the user so the images can be displayed and compared. The comparison workflow is intended to use browser-local object references and processing. RFE does not intentionally upload the selected comparison images to an RFE server as part of this workflow.

Ad Comparer

Ad Comparer may access a URL or local content deliberately supplied by the user so that content can be displayed and compared. When the user asks the extension to load an external URL, the browser necessarily communicates with that destination and the destination may receive ordinary network information such as the user’s IP address and browser request information under that destination’s own privacy practices. This communication is between the browser and the user-selected destination and is not an RFE sale of user data. Ad Comparer may use Chrome local storage for settings or comparison state required for its user-facing workflow.

Side Comparer

Side Comparer processes content the user deliberately places into its comparison interface to provide a side-by-side review experience. The content is used for that user-requested comparison function.

5. Chrome Permissions

RFE intends to request only Chrome permissions necessary for the disclosed single purpose and user-facing features of each extension. Permissions are not intended to be requested merely for possible future functionality. Where a tool requires access to a webpage, URL, local file, side panel, or local extension storage, that access is used to provide the corresponding comparison, validation, display, or settings feature.

If an extension’s functionality changes in a way that requires additional data access or permissions, RFE will update the applicable disclosures and this policy as appropriate before relying on the new data practice.

6. Data Sharing, Sale, and Advertising

RFE does not sell extension user data. RFE does not transfer extension user data for personalized advertising, retargeting, interest-based advertising, creditworthiness, lending, or data-broker purposes.

RFE does not intentionally share user-selected creative files or comparison content with third parties through an RFE-operated server. A user-directed request to load a third-party URL necessarily sends a request to that third-party destination. Information voluntarily sent by email is also processed by the user’s and RFE’s email service providers as necessary to deliver the communication.

RFE may disclose information when required by applicable law or when reasonably necessary to protect security, investigate abuse, or protect legal rights. If RFE later introduces a service provider that receives extension user data, this policy will be updated to identify the relevant category or party and purpose before such sharing is relied upon.

7. Chrome Web Store Limited Use Disclosure

RFE’s use of user data obtained through Chrome extension permissions is limited to providing or improving the extension’s disclosed single purpose and user-facing features. RFE will not use or transfer that data for personalized, retargeted, or interest-based advertising.

RFE will not transfer such user data except when necessary to provide or improve the disclosed user-facing feature, to comply with applicable law, for security purposes such as investigating abuse, or as otherwise permitted by the Chrome Web Store User Data Policy.

RFE does not permit humans to read user data obtained through extension permissions except when the user gives affirmative consent for a specific support purpose, when necessary for security or abuse investigation, when required by law, or where the data has been appropriately aggregated and anonymized for permitted internal operations.

8. Retention and Deletion

RFE does not intentionally maintain a central repository of user-selected creative files processed in the local workflows described above. Browser-local settings or state may remain in Chrome’s extension storage until cleared by the user, removed by Chrome, or deleted when the extension is uninstalled, depending on Chrome’s behavior.

Support emails may be retained for as long as reasonably necessary to answer the request, maintain useful support history, protect against abuse, or meet legal obligations. Users may request deletion of support information under RFE’s control by contacting the email address below, subject to legitimate legal or security retention requirements.

9. Security

RFE uses a data-minimization approach: access should be limited to what is necessary for the extension’s disclosed functionality, and local browser processing is preferred where practical. No method of electronic processing or transmission is completely secure, so absolute security cannot be guaranteed.

10. User Choices and Control

Users control which files, images, URLs, or other content they deliberately provide to the tools. Chrome provides controls for extension permissions and extension removal. Users can uninstall an RFE extension at any time through Chrome. Where applicable, locally stored extension data can be cleared through Chrome’s extension or site-data controls.

11. Children

RFE tools are general-purpose creative-QA utilities and are not directed to children. RFE does not knowingly design these tools to collect personal information from children.

12. Changes to This Policy

RFE may update this policy when tool functionality, Chrome permissions, service providers, or legal and platform requirements change. Material changes will be reflected on this page and the effective date will be updated. Data practices will not be expanded merely by changing this policy; the extension’s behavior and required user disclosures must also remain consistent with applicable requirements.
